# Формат VPK и инструменты

## VPK (Valve Pack)

### Определение
- **Тип**: Valve Pack архив (Source Engine)
- **Не**: Valve Particle System
- **Автор**: Valve Corporation
- **Назначение**: Упаковка игровых ресурсов

### Структура
- Содержит: модели (.mdl), материалы (.vtex), звуки (.wav), текстуры (.vtex), скрипты, карты
- Загружается в числовом порядке: pack000.vpk → pack001.vpk → ...
- Более новые версии файлов могут быть в более поздних архивах

### Инструменты для работы с VPK
- **Turvy's VPKTool** (Extras/Developer Tools/Turvy's VPKTool)
  - Распаковка VPK архивов
  - Конвертация текстур (.TTZ → .vtex)
  - Просмотр содержимого
  - Версия: 3.9a

### Важные примечания
- Распаковывать VPK **перед** установкой патчей
- Порядок распаковки: по возрастанию номера
- В противном случае старые версии файлов перезапишутся

## Инструменты исследования

### Встроенные инструменты
- **Hammer.exe** — редактор карт (.vmf)
- **vbsp.exe / vrad.exe** — компиляция карт
- **studiomdl.exe** — создание моделей
- **vtex.exe** — обработка текстур
- **soundbrowser.exe** — просмотр и редактирование звуков

### Внешние инструменты
- **Turvy's VPKTool** — работа с VPK архивами
- **ZylonBane's ZVTool** — консольные утилиты
- **Entity Lists** — текстовые файлы с сущностями карт

## Доступ к ресурсам без изменения установки

### Через SDKContent\VpkContent
- Все извлечённые ресурсы доступны для чтения
- vdata\system\ — системные данные (правила, характеристики, NPC, квесты)
- vdata\quotes.txt — диалоги
- materials\, models\, sound\ — игровые ресурсы

### Через VPKTool
- Распаковка в отдельную папку для исследования
- Не требует изменения исходных файлов

### Через Python скрипты
- Extras/Developer Tools/Original Python Files/ — скрипты локаций
- Unofficial_Patch/python/ — модифицированные скрипты
